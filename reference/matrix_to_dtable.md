# Converting a Matrix to data.table

Wrapper function that converts a sparseMatrix to data.table

## Usage

``` r
matrix_to_dtable(x)
```

## Arguments

- x:

  A [matrix](https://rdrr.io/r/base/matrix.html),
  [sparseMatrix](https://rdrr.io/pkg/Matrix/man/sparseMatrix.html) or
  [Matrix](https://rdrr.io/pkg/Matrix/man/Matrix.html).

## Value

A [data.table](https://rdrr.io/pkg/data.table/man/data.table.html)
class.
